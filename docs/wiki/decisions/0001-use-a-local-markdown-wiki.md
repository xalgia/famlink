# 0001: Use A Local Markdown Wiki

Date: 2026-04-16

## Status

Accepted

## Context

The project is in early planning and needs a lightweight place to keep product thinking, technical notes, open questions, and durable decisions close to the code.

## Decision

Use Markdown files under `docs/wiki/` as the local project wiki.

## Consequences

- Project context stays versioned with the code.
- Notes can start rough and become more structured over time.
- The wiki can later be published, migrated, or mirrored if the project needs a hosted documentation space.
