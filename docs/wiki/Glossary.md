# Glossary

Use this page to define project terms as they become important.

| Term | Meaning |
| --- | --- |
| FamLink | Working project name. |
| Voice-note intercom | The current product model: every message is a stored voice note, while live mode controls whether new notes auto-play. |
| Live mode | A playback preference that auto-plays newly received voice notes when the receiving app is active/listening and playback is allowed. |
| Tile | A large home-screen contact control backed by one approved Matrix relationship room. |
| Matrix room | The Matrix conversation container used for membership, history, events, and voice notes. |
| `m.audio` | Matrix message type for an audio clip. FamLink voice notes should be represented this way. |
| Synapse | Matrix homeserver implementation being considered for FamLink's backend. |
