# FamLink Wiki

This is the local Markdown wiki for shaping the project before and during implementation.

## Start Here

- [Project Brief](Project-Brief.md): the current product intent, users, scope, and open questions.
- [Product Notes](Product-Notes.md): feature ideas, user flows, and rough UX thinking.
- [Architecture](Architecture.md): technical direction, system boundaries, and implementation notes.
- [Research](Research.md): links, comparisons, assumptions, and findings.
- [Decisions](Decisions.md): durable decisions and links to decision records.
- [Glossary](Glossary.md): shared language for domain terms.
- [Meeting Notes](Meeting-Notes.md): dated notes from planning sessions.
- [Worklog](Worklog.md): active progress notes, commands, blockers, and next steps.

## Wiki Conventions

- Keep pages readable as plain Markdown.
- Use dated headings like `2026-04-16` for notes.
- Put durable technical or product choices in `decisions/`.
- Keep the worklog current while making changes.
- Prefer small updates over perfect documentation.
